# STePS promotional media

The public assets are copied unchanged by Vite into the production build:

- Poster: https://hillgpx.com/media/steps-poster.png
- Promotional video: https://hillgpx.com/media/steps-video.mp4
- Landscape project preview: https://hillgpx.com/media/steps-preview.jpg

The poster uses real desktop screenshots. The 25.7-second video shows recorded
desktop interactions with editorial captions and an instrumental soundtrack
generated for this promotion through Runway. The preview is a frame from that
video. The interface was captured on 29 October 2026.

Map attribution is included in the media: © OpenStreetMap contributors
(https://www.openstreetmap.org/copyright) and OpenFreeMap
(https://openfreemap.org/).

Keep these paths stable for the STePS listing. These files are promotional site
assets, not user-uploaded route media. They load only when requested directly.
